# spatial/

Contracts for room geometry and its visualisation. Status of each part:

| Path | What | Status |
|---|---|---|
| `room-models/ROOM_MODEL.schema.json` | JSON Schema (2020-12) of `RoomDesignInput`, the input every room engine consumes (`packages/domain-types/src/room.ts`) | **IMPLEMENTED** — checked against 15 engine-generated template rooms and the 92 demonstrator golden-case inputs: 107/107 valid (`node room-models/validate.mjs && python3 -I room-models/check_schema.py`) |
| `room-models/examples/*.json` | one real engine input per template (synthetic, generated) | generated by `validate.mjs` |
| `geometry/GEOMETRY.md` | coordinate system, units, outline rules, provenance | **IMPLEMENTED** rules, documented from `packages/commissioning-engine/src/geometry.ts` and `design.ts` |
| `browser-3d/SCENE_CONTRACT.md` | the room-scene JSON a 3D viewer consumes | contract **EXISTS in the demonstrator** (export `empathia.room-scene.v1`); production viewer **SPECIFIED ONLY** |
| `ue5-contracts/UE5_CONTRACT.md` | how an Unreal Engine experience would consume rooms | **SPECIFIED ONLY** — no UE5 code, project or asset exists |

Nothing here contacts a device or renders a native engine build. All room data in this repository is synthetic.
