# Founder Studio inputs

The studio's data is generated by `apps/founder-studio/scripts/build-data.mjs` from these files and from the repository itself.
They are committed so that `node scripts/build.mjs --studio` builds the complete studio on any machine, CI included. Their SHA-256
values are in `INPUTS.json`, and `scripts/verify/studio-inputs.mjs` checks them on every studio build.

| File | What it is |
|---|---|
| `founder-edition/Empathia-Living-Campus-v2.5.4-nomedia.html` | The founder-supplied V2.5.4 Founder Edition (synthetic data, no embedded media). The studio serves it under `demonstrators/founder/`, and the town-hall end-to-end test drives it. |
| `source-254/v25-60-room.js`, `v52-room.css`, `v30-aurora.css` | The original Build a Room engine and styles that the studio's Source view shows beside the TypeScript port |

**Not here, by design:** the film masters. They are large, and their rights are unverified for any external channel. The studio
plays them from the founder's own film folder. CI uses synthetic fixture videos to test the same player and server path, and the test
records which kind it used.

These files are internal: the repository is private, and the studio runs only on the founder's own computer. Nothing here is
published by the public sites.
