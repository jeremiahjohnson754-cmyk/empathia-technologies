# Lite spatial restoration: matrix against the founder's 50/10 directive

**State on 13 November 2026: in progress. Lite parity is NOT achieved.** The open items are listed in §4.
Each line of the directive is marked with one of these:

- **RESTORED**: present and covered by a named test.
- **PARTIAL**: some of it is present; the gap is stated.
- **NOT RESTORED**: absent.
- **NOT RUN**: the check exists but has not been run yet.

Screenshots, written plans and design concepts count for nothing here. Only behaviour a test drives through the page counts.

The authority is V2.5.3 itself. `legacy/source/v253/` holds the founder's files; they are engineer-private and not in version control.
The room interiors are now V2.5.3's own code: `apps/demo/src/lite/v253/vendor.js` holds 125 definitions, regenerated byte-for-byte
by `scripts/legacy/vendor-v253-room.mjs`. They run on this campus's room records through `v253room.ts`, not on a re-drawing.
