# Workflow masterclass matrix — W01 to W26

Generated by `node scripts/docs/workflow-matrix.mjs`. The workflow sentences are the Surpass directive's. Every address and test file named
is checked to exist when this file is written.

**2 of 26 can be done end to end in the demonstration, 22 are partly built, 2 are not built.** "End to end in the
demonstration" means on synthetic data, in a browser, with tests; it does not mean a customer workflow has run.

The directive also asks, for every workflow, for a specification, a UI state map, a sequence flow, screenshot or video evidence, and
normal and adversarial tests. **None of the 26 has that full set yet.** This matrix is the honest starting inventory, not that set.
