# Feature parity ledger (deliverable H)

The full ledger against the originals (Living Campus V2.5.3, Founder Edition 2.5.4, Founder Studio) is `docs/legacy-parity.md` /
`docs/legacy-parity.csv`, generated by `scripts/legacy/parity-ledger.mjs`. This file records what today's work did to features, in the
directive's five kinds, so that nothing was lost without saying so.
