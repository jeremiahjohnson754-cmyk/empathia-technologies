# Feature maturity

Words used: **implemented** (in the code), **tested** (a suite checks it, automated), **simulated** (it acts on synthetic state and says
so), **mock-tested** (an adapter checked against a mock only), **planned**, **not run**. Nothing is called production-ready.

The per-feature states are in `docs/restoration/PARITY_MATRIX.md`, `docs/restoration/LITE_INVENTORY.md`,
`docs/restoration/SIGNAL_INVENTORY.md` and `docs/surpass/ENGINEERING_CHECKPOINT.md` (Simulated, pending, blocked). This file takes over
as products are transformed.
