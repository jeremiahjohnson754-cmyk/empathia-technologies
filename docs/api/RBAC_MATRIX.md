## Checks beyond the authority

| Endpoint | Further rule (where enforced) |
|---|---|
| `POST /v1/rooms/{room}/results` | The caller’s role must be one of the test’s responsible personas (`cx_plan_row.personas`), or `cxeng` / `architect` (`RECORD_OVERRIDE_PERSONAS`); room in COMMISSIONING; test applicable; accepted evidence kind; stored evidence object; instrument named for instrument-measured tests — `packages/commissioning-engine/src/recording.ts` `recordBlockers`, and trigger EM002 in the database. |
| `POST /v1/rooms/{room}/results/{test}/verify` | Only a recorded PASS, never by the person who recorded it, never twice — `verifyBlockers`, CHECK `verification_is_independent` and trigger EM003. |
| `POST /v1/rooms/{room}/lifecycle` | One governed step at a time; DESIGN_APPROVED needs an approved classification, a saved revision and no open High/Critical design deficiency; ACCEPTED needs every applicable test PASS_VERIFIED and no open issue; OPERATIONAL needs live monitoring evidence (never present in the starter) — `lifecycle.ts` `lifecycleBlockers`. |
| `POST /v1/issues/{issue}/work-orders` | Only for an OPEN installation/commissioning deficiency (a design deficiency gets a design change) — `commissioning.ts` `createWorkOrder`. |
| Every room-scoped endpoint | A site-scoped member sees and changes only rooms in buildings of their sites (404 otherwise) — `rooms.ts` `findRoom`, `createRoom`. |
| `POST /v1/integrations/{key}/sync` | Only runnable MOCK adapters; everything else answers 501 not_configured — `integrations/sync.ts`. |
