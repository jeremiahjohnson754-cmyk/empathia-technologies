## 403 — the role lacks the authority

The designer may not approve a design. The refusal is also written to the audit trail as DENIED.

```http

{
  "to": "DESIGN_APPROVED"
}
```

## Idempotent replay

The same key and the same body: the first response is returned again (`idempotent-replay: true`) and no second room is created.

```http
POST /v1/rooms HTTP/1.1
Authorization: Bearer <access token>
Content-Type: application/json
idempotency-key: docs-example-0001

{
  "name": "Example Huddle (synthetic)",
  "template": "huddle",
  "buildingCode": "NST",
  "floor": 1
}
```

```http
HTTP/1.1 201
content-type: application/json; charset=utf-8
x-correlation-id: 16cbfc51-4e32-4f21-beaa-b1750ceda472
idempotent-replay: true

{
  "id": "987f5716-696c-402f-8405-b4e7711787b2",
  "code": "R-PLN-0004"
}
```
