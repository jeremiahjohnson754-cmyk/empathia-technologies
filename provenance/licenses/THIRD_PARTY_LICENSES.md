# Third-party software and licences

Source of truth: `../sbom/empathia-sbom.cdx.json` (CycloneDX 1.5, generated by `../scripts/build_vault.py` from what is actually installed and linked) and `LICENSE_TEXT_INDEX.json` (which licence texts were found on disk and copied into `texts/`).
This is an engineering inventory to support review by counsel. It is not a legal opinion and not a licence-compliance certification.

## What ships and what does not

| Scope | Meaning | Components |
|---|---|---|
| **Bundled into an app** (`scope: required`) | Copied into `studio.js` / `app.js` by esbuild, so every build that is handed to anyone carries them | react 19.2.8, react-dom 19.2.8, scheduler 0.27.0 — all MIT |
| **Needed by a running service, not shipped** | Installed on the machine that runs the starter | PostgreSQL 16.15 (PostgreSQL Licence), Node.js 22.22.0 (MIT, with bundled third-party components listed in its own LICENSE); for the Python intelligence service and the synthetic ML prototype: starlette 1.6.0, uvicorn 0.53.0, pydantic 2.13.5 (+ pydantic_core, annotated-types, typing-inspection, typing_extensions), anyio, h11, idna, click, numpy 2.5.3, scikit-learn 1.9.1, scipy 1.18.1, joblib, threadpoolctl, narwhals, cloudpickle — all BSD/MIT/PSF-style permissive (exact versions and licences in the SBOM) |
| **Development / build / test tooling** (`scope: optional`) | Used to build or test; never inside a delivered build | typescript 6.0.3 (Apache-2.0), esbuild 0.28.2 + @esbuild/linux-x64 (MIT), @types/node 26.2.0 (MIT), undici-types 8.3.0 (MIT), marked 18.0.10 (MIT, build-time Markdown rendering), playwright / playwright-core 1.56.0 (Apache-2.0), Chromium 141.0.7390.37 Playwright build (BSD-3-Clause and many others), FFmpeg 6.1.1 (LGPL-2.1+/GPL-2.0+, build-dependent), @mermaid-js/mermaid-cli 11.16.0 (MIT), Python 3.13.16 (PSF) |

First-party code with no third-party runtime dependency: the enterprise API uses Node's own `http` module and a PostgreSQL wire-protocol client written in this repository (`services/enterprise-api/src/db/pg.ts`), so it has **no third-party npm runtime dependency**. The repository's Python scripts import only the standard library; `ml/` and `services/intelligence-python/` import numpy, scikit-learn, joblib, starlette and pydantic, and the service is launched with uvicorn (`../sbom/PYTHON_IMPORTS.json` lists every import and the file that makes it; transitive requirements are resolved from installed metadata). Re-run `../scripts/build_vault.py` whenever dependencies change.

Fonts: no font file ships. The design tokens use system font stacks only (`ui-sans-serif, system-ui, …`), so no font licence applies to delivered builds.

## Licence texts

`texts/` holds the licence files found next to each component (33 of 35 components at generation; the current figure is in `LICENSE_TEXT_INDEX.json`). **NOT_FOUND:** `@esbuild/linux-x64` (platform binary package ships no licence file; esbuild's MIT `LICENSE.md` covers it per its package metadata) and the Chromium Playwright build (no licence file in `/opt/pw-browsers`). Hashes of every copied text are in `LICENSE_TEXT_INDEX.json`.

## Not present offline

`@types/react` and `@types/react-dom` are named in `package.json` but were not available offline; a local type shim (`tooling/types/react-offline`, first-party) stands in. When a connected machine runs `pnpm install`, re-run the SBOM.
